# BREATHE.EXE folder map

| Folder | Intended contents |
| --- | --- |
| Assets/_Breathe/Scenes | Main.unity starter scene; future game scenes |
| Assets/_Breathe/Prefabs | Future reusable interviewer, room, and UI objects |
| Assets/_Breathe/Scripts | Empty reserved Core, Interview, Presentation, Integrations, and UI folders |
| Assets/_Breathe/Art | Characters, Environment, Materials, and Textures |
| Assets/_Breathe/Audio | Music, Ambience, SFX, Voices, and Mixers |
| Assets/_Breathe/UI | Future UI assets |
| Assets/_Breathe/Settings | Future project-specific configuration assets |
| Assets/_Breathe/Editor | Reserved for future editor tools; no custom tools yet |
| Assets/_Breathe/Tests | Reserved EditMode and PlayMode tests; no custom tests yet |
| Assets/Settings | Unity template URP renderer, pipeline, and volume settings |
| Assets/ThirdParty | Reviewed vendor assets, where the vendor permits this layout |
| Services | Empty folder for the future API/hardware companion service |
| AssetInbox | Ignored raw downloads, reviewed before import |
| docs | Setup, asset source/license register, hardware inventory, and assistant instructions |
| Packages | Unity package manifest and lock file |
| ProjectSettings | Unity-generated shared project settings and editor version |
| Builds | Ignored local test/export builds |
| dumb | Existing repository music files, retained outside the Unity project assets |

Move and rename assets in Unity where practical. Always preserve the matching .meta file and its GUID. Import only licensed, reviewed assets compatible with URP. The current starter scene contains only the template camera, light, and global volume; no game has been programmed.
