Mac setup / signing

The helper uses SmartSpectra 3.4.0. It needs an Apple Development identity and a matching provisioning profile for Keychain access. Install full Xcode, sign into Xcode → Settings → Accounts, then follow docs/INTEGRATIONS.md in the project. This panel can detect cameras even when full measurement signing is incomplete.
